# Changelog

## Initial public preservation release

Publishes the tested packages, editable package contents, rebuild tools and validation records.

### Brake Without Losing Reserves 0.2.0

Bypass the entire brake-specific boost eligibility branch, retaining normal reserve aging and damage invalidation. The superseded 0.1.0 experiment skipped only a cancellation flag and could still expire accumulated reserves using a shorter base sustain duration. That obsolete package is not distributed here.

### Triple Drift Reserves 0.1.0

Triple banked drift boost awards for Good through Perfect across all chain stages and player driving styles, by changing 102 sustain fields in three original-dependent archive-entry deltas.
